# Security

Report vulnerabilities through [GitHub's private vulnerability reporting](https://github.com/GillMacedo/panelgap/security/advisories/new), not in a public issue.

panelgap only reads the files it's given and opens no network connection. A wrong finding, or a broken query it misses, is a normal bug. If a crafted dashboard, rule file or scrape can make it do something other than read and report, report that privately. panelgap is a diagnostic aid and doesn't enforce anything.
